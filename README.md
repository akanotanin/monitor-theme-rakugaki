# rakugaki

![rakugaki](preview.png?v=5)

极简探针（[Monitor](https://github.com/monitor-probe/monitor)）的第三方主题，源码基于上游默认主题
`monitor-theme-default` v1.1.0 改造。纯静态前端，只读 hub 的公开接口，
国旗、图标与字体都自带，离线可用。

## 预览

![节点地球](preview-globe.png?v=6)

列表页顶部那颗地球（默认开着）：海岸线与针都自带、不连任何外部服务；可拖拽旋转、没人碰时自转，
点一枚针、或点地区列表里的一行＝打开那台的整页详情（整队 ≥30 台、或同一地区 ≥5 台时聚成带台数的针）。
动作遵系统的「减弱动态效果」；窄屏与桌面同一档，拖动只接管横向。

六种卡片形态（默认是「延迟」）：

|:---:|:---:|
| ![简约形态](preview-plain.png?v=6) | ![经典形态](preview-classic.png?v=7) |
| **延迟形态（默认）** | **详细形态** |
| ![延迟形态](preview-latency.png?v=8) | ![详细形态](preview-detailed.png?v=7) |

| ![总览形态](preview-wide.png?v=2) | ![紧凑形态](preview-compact.png?v=6) |

整页详情里那张延迟图：**滚轮**收放纵向范围（光标在图上时页面不跟着滚）、**左键上下拖**平移、
**双击或「重置」**回自动量程；只在这一张上生效，列表里紧凑展开的小图不抢滚轮。时间量程按 hub 的
保留天数给。

## 主题设置

后台「主题」页的「主题设置」，改完对访客立即生效（值存在 hub 的站点配置里，访客端不留副本）。
地球、明暗、卡片形态三处，访客能在顶栏自己覆盖：列表页顶栏那枚墨线圆盘图标＝六档形态菜单，
选完立刻生效、只记在他自己的浏览器里，选回与站长相同的那档＝重新跟着站长的设置走。
站点图标自 hub 1.4.0 起由面板「设置 → 站点图标」管（换主题也保留），主题自带的那份只在没设时兜底。

| 设置项 | 默认 | 说明 |
|---|---|---|
| 节点地球 | 开 | 列表页顶部那颗会自转的地球；关掉＝整块不渲染，顶栏那枚开关也一起收起。 |
| 列表页顶部 | 两个都显示·概览卡片价值版 | 分组标签行与概览卡片行的六种组合：都不显示／只分组标签／只概览卡片（原版或价值版）／两个都显示（原版或价值版）。价值版把前两张换成「月度预算」与「剩余价值」（按汇率折人民币，拉不到用内置兜底表，故标 ≈；买断与没填价的不计）。 |
| 卡片形态 | 延迟 | 访客默认看到的档：**经典**（2×2 四格）／**简约**（实时速率 + 累计总量）／**延迟**（简约同款 + 三网延迟，默认）／**详细**（再加在线时长、价格与到期）／**总览**（四列小卡）／**紧凑**（一行一台表格，点一行就地展开延迟图）。 |
| 备注显示位置 | 卡片与详情页都显示 | 四选一：都显示／只卡片／只详情／都不显示。备注在 hub 后台的节点里填，有公开（访客可见，hub ≥ 1.3.2）与私有（仅登录管理员）两处；半角 `,` 与全角 `，` 分隔、各成小卡片，私有那条按换行也能拆，显示时带锁 + 描边、私有在前。 |
| 显示的延迟线路 | 空（自动） | 「三网延迟」（延迟、详细两档）显示哪几条线路：一行一个 ping 任务名（最多三条），留空按后台顺序取前三条；对不上的名字跳过。每 60 秒刷新。 |
| 主题模式 | 随系统设置 | 四选一：随系统／随北京时间自动（19:00–07:00 暗色，固定 UTC+8）／亮色／暗色。 |

## 安装与许可

从 [Releases](https://github.com/akanotanin/monitor-theme-rakugaki/releases) 下载 `theme.tar.gz` 上传到
探针后台，之后可在主题卡片上点「从 GitHub 更新」。MIT（上游 `monitor-theme-default` 的版权与许可
照留，见 [LICENSE](LICENSE)）；随包的四款字体以 SIL Open Font License 1.1 授权，见 [FONTS.md](FONTS.md)。
