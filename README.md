# rakugaki

![rakugaki](preview.png?v=2)

极简探针（[Monitor](https://github.com/monitor-probe/monitor)）的第三方主题，源码基于上游默认主题
`monitor-theme-default` v1.1.0 改造。纯静态前端，只读 hub 的公开接口，
国旗、图标与字体都自带，离线可用。视觉语言参考 [cc-router](https://ccrouter.app/)，
代码与那个项目没有往来（见 [FONTS.md](FONTS.md) 的「视觉参考」一段）。

## 预览

节点地球：

![节点地球](preview-globe.png?v=3)

列表页顶部那颗正射投影的地球（默认开着；站长在主题设置里关掉＝整块关，顶栏那枚图标也一起
收起；开着时访客可以自己关，选完记在他自己的浏览器里）。

- **地球本身**：79 个环、1483 个点的海岸线（主题自带，不连任何外部服务），每 30° 一条经纬网、一条会缓慢扫过的经线，背面的大陆一概不画；拖拽可以转它（横向 0.48°/px、纵向 0.36°），没人碰的时候自己慢慢转，钉住某个地区后就停下；系统开了「减弱动态效果」则不转。
- **针：小队一台一枚，大机群一个地区一枚**：落点按国家算，名字里认得出城市就按城市（香港、东京、新加坡……）；整队 ≥30 台、或同一地区 ≥5 台时，同城的机器聚成一枚**带台数的针**，小队里仍是一台一枚、同一地区的自动岔开。引线连到左右两摞标签上（左侧「名字 · 国家」、右侧「国家 · 名字」，按地理位置分流、数量自动配平）。点针直接进那台机器的详情页。
- **右侧地区列表**：按地区分组与台数，点一行＝地球飞过去并钉住，同时**下面那张列表只留该地区的机器**；再点一次、或点「全部」＝取消筛选、继续自转。切分组标签时地球与地区列表跟着变（与概览卡片同一口径）。
- **窄屏**：与桌面同一档（海岸线、扫掠、连线都在），圆盘按窄屏比例排布；拖动只接管横向，竖划仍然是滚页面。
- **顶栏入口图标（自动探测，没有设置项）**：本站 `/chicken/` 上装了那座 3D 小鸡农场才出现，没装就什么都不显示、不占位（判据是「那条接口回的是不是 JSON」，不是状态码——hub 对未知路径会回落到主题首页并回 200）。装了就有，不必配；也没有「指向别处」或「关掉」这两档。

## 访客自己换卡片形态

顶栏那枚方形图标（列表页才有）点开是五档：**经典 / 简约 / 延迟 / 详细 / 紧凑**，与后台设置里那五档一一对应，选中的打勾、站长在后台设的那一档标「默认」。

- **选完立刻生效、刷新还记得**，但只记在访客自己的浏览器里（localStorage），**不写 hub** —— 后台那格是「默认看到哪种」，访客自己的偏好不该改到全站。
- 选成**与后台设置相同**的那一档时，记录会被删掉 ＝ 回到「跟着站长的设置走」；这样站长以后改默认，没自己挑过的访客也会跟着变。
- 认不出的存值（旧版本、手改）一律当作「没选过」，退回后台设置的那一档；旧名 `detail` 会迁到「延迟」。
- 点别处或按 `Esc` 收起。只影响列表页：详情页不受它影响，也没有这枚菜单。

## 关于备注

备注有**两处来源**，都在 hub 后台的节点里填：

1. **「公开备注」**（hub ≥ 1.3.2，单行 ≤100 字）——写给访客看的那条，随公开视图下发，匿名访客也拿得到；
2. **「私有备注」**——写给自己的那条，只下发给登录的管理员，
   访客拿不到。

**两边写法一致**：逗号分隔就是多枚，一枚一枚各自成小卡片（半角 `,` 与全角 `，` 都认，两侧空白削掉、
空片段丢掉）；私有那条多一手「按换行也拆」（hub 对它没有单行约束，常有人把几件事分行写）。

**两处合并显示**：卡片与详情页摊的是**私有 + 公有**合成的一串——私有在前（带锁 + 描边，只有登录的
自己看得到），公有在后。访客那边 hub 不下发私有备注，所以同一个位置他们看到的只有公有那几枚。


## 主题设置

后台「主题」页的「主题设置」，改完对访客立即生效（值存在 hub 的站点配置里，访客端不落副本）：

**站点图标不在这一页**：hub 1.4.0 起由面板的「设置 → 站点图标」管 —— 选好之后浏览器标签页、
书签、手机主屏幕与顶栏那枚手绘方标一起换，**换主题也保留**；主题自带的那份只在没设图标时兜底。

| 分组 | 设置项 | 默认 | 说明 |
|---|---|---|---|
| 列表与卡片 | 节点地球 | 开 | 列表页顶部那颗会自转的球（每台机器一枚针、一条引线连到左右两摞地区标签，旁边一条一条列着地区）。关掉＝**整块不渲染**（顶栏那枚地球图标也一起收起，页面上不留一个点了没落点的按钮），版面更安静、也不再去算岸线。开着时访客可以在顶栏那枚图标上自己关/开，以他的为准（只存在他自己的浏览器里）；他再点回与这里相同的那一档，就重新跟着这里的设置走。 |
|  | 列表页顶部 | 两个都显示·概览卡片价值版 | 列表页顶部显示什么，六选一：**都不显示**／**只显示分组标签**／**只显示概览卡片·原版**／**只显示概览卡片·价值版**／**两个都显示·概览卡片原版**／**两个都显示·概览卡片价值版**（默认）。分组标签 = 那一行「全部 / 各组 / 未分组」，节点本来就没有分组时无论如何都不显示；概览卡片 = 那行统计卡片，数据都取自节点列表本身、不多发请求，**数字跟着分组标签选中的那一档走**（选「全部」时就是全站；不存在标签行时自然一直是全站），只有实时网速那张下面那条走势线画的是访客打开页面后的实时速率，刷新页面就从空的重新攒。原版是四张卡片各一块读数（节点在线数、最忙节点、今日与累计流量、全站实时网速）；月度预算剩余价值版把前两张各排两块读数——第一张是「月度预算」与「剩余价值」，第二张是「节点」与「最忙节点」（两块分居卡片两端）。**月度预算** = 各节点价格按计费周期摊到每月后相加；**剩余价值** = 已付但没用完的那一段（价格 × 剩余天数 ÷ 周期天数）；两者都按主题里写死的固定汇率折成人民币显示（因此写「≈」，口径与汇率在悬停提示里），一次性买断、没填价格、没有到期日的机器不计入。默认值 1.5.1 起改成「两个都显示·概览卡片原版」，已经保存过这一项的站点不受影响。 |
|  | 卡片形态 | 简约 | 卡片长什么样，五选一：「经典」网络速率与总量分两行（2×2 四格）；卡面不含延迟——那三条延迟收在右上角那枚信息图标的浮层里（点开才去取）；「简约」网络收成一行（左边实时速率、右边累计总量），读数那一层另换一套视觉——标签用墨色而不是弱化灰、进度条更细、底注更小、格行距更紧，同样不含延迟；「延迟」再加上三网延迟；「详细」在延迟之上再添在线时长、价格与到期；「紧凑」换成一行一台的表格（名称 / 系统 / 在线 / 剩余 / 价格 / 负载 / 网速 / CPU / 内存 / 硬盘 / 流量，列随屏宽收放、每个指标带一条细进度条），一屏能排下两三倍。**紧凑形态点一行就地展开**——展开行里挂的是那张带 1 / 6 / 24 小时 / 7 天范围与削峰开关的延迟图（不跳详情页），要去整页详情点展开行右上角的入口。五种形态配色与读数口径一致，只有信息多少与排布不同（进度条统一是**墨色的 70%**：一页几十台时不会连成一片黑条，低负荷的短条也还看得出来）。 |
| 节点信息 | 备注显示位置 | 卡片与详情页都显示 | 备注小卡片摊在哪儿：`卡片与详情页都显示`（默认）/ `只在卡片上显示` / `只在整页详情里显示` / `都不显示`。「卡片」＝列表里那几处（经典/延迟右上角那枚浮层、详细档标题行、紧凑展开行那格）；「详情页」＝点进去那一整页（规格下面那一串）。备注**内容**在后台节点里填（见「关于备注」）。 |
|  | 显示的延迟线路 | 空（自动） | 卡片「三网延迟」里显示哪几条线路。每行一个 ping 任务名，最多三个，按填写的顺序显示；留空则按后台顺序自动显示前三条。名字对不上（改过名、任务删了）那一行跳过。在「经典」（右上角那枚浮层里）、「延迟」「详细」「紧凑」形态下生效，数据每 60 秒刷新一次。 |
| 外观 | 主题模式 | 随系统设置 | 整站的明暗，四选一：**随系统设置**（默认，跟访客的 `prefers-color-scheme` 走）／**随北京时间自动切换**／**亮色**／**暗色**。「自动」按**北京时间 19:00–07:00 用暗色、其余用亮色**（中国不实行夏令时，固定 UTC+8），页面开着跨过这两个点也会自己换过来（每分钟问一次钟点）。访客点过顶栏那枚太阳/月亮图标就以他的为准（同样只存在他自己的浏览器里，点回与这里相同的一档＝重新跟着这里走）。 |

## 安装

首次安装需从 Releases 下载 theme.tar.gz 上传至探针后台，后续可在主题卡片上点击从 GitHub 更新。
