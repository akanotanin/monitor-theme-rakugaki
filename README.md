# rakugaki

![rakugaki](preview.png?v=5)

极简探针（[Monitor](https://github.com/monitor-probe/monitor)）的第三方主题，源码基于上游默认主题
`monitor-theme-default` v1.1.0 改造。纯静态前端，只读 hub 的公开接口，
国旗、图标与字体都自带，离线可用。

## 预览

![节点地球](preview-globe.png?v=6)

列表页顶部那颗地球（默认开着）：海岸线与针都自带、不连任何外部服务；可拖拽旋转、没人碰时自转、
钉住某地区后停下，系统开了「减弱动态效果」则不转。点一枚针、或点地区列表里的一行＝打开那台的整页
详情（多台共用一枚针时打开第一台；从它们上面拖拽仍然是转地球）。整队 ≥30 台、或同一地区 ≥5 台时
聚成一枚带台数的针。地区名认得出城市就写城市（`US · Phoenix`），否则写国家名（`United States`）；
认不出国家的机器不上地球、也不进地区列表（但照算在「全部」里）。窄屏与桌面同一档，拖动只接管横向。

顶栏那枚农场入口图标是自动探测的：站点装了 3D 小鸡农场才出现，没装就什么都不显示、也不占位。

整页详情（点开任意一台）里那张延迟图：**滚轮**收放纵向范围（光标在图上时页面不跟着滚）、
**左键上下拖**平移这段范围、**双击或「重置」**回自动量程；只在整页详情生效，列表里紧凑展开的那张
小图不抢滚轮。时间量程按 hub 的保留天数给：1／6／24 小时一直都在，够得着才多出 7 天、30 天与
保留天数本身。

## 访客自己换卡片形态

顶栏那枚墨线圆盘图标（列表页才有）点开是六档：**经典 / 简约 / 延迟 / 详细 / 总览 / 紧凑**，选中的
打勾、站长在后台设的那档标「默认」。选完立刻生效、刷新还记得（只记在访客自己的浏览器里）。
点别处或按 `Esc` 收起。

## 关于备注

备注在 hub 后台的节点里填，有**公开**（写给访客，hub ≥ 1.3.2，单行 ≤100 字）与**私有**（写给
自己，只下发给登录的管理员）两处；半角 `,` 与全角 `，` 都算分隔、一枚一枚各自成小卡片，私有那条
按换行也能拆。显示时两处合成一串：私有在前（带锁 + 描边，只有登录的自己看得到）、公有在后；
摊在哪儿由「备注显示位置」决定。

## 主题设置

后台「主题」页的「主题设置」，改完对访客立即生效（值存在 hub 的站点配置里，访客端不留副本）。
「地球」「明暗」「卡片形态」三处，访客都能在顶栏自己覆盖，只记在他自己的浏览器里；选回与站长
相同的那档＝重新跟着站长的设置走。

**站点图标不在这一页**：hub 1.4.0 起由面板的「设置 → 站点图标」管（换主题也保留），主题自带的
那份只在没设图标时兜底。

| 设置项 | 默认 | 说明 |
|---|---|---|
| 节点地球 | 开 | 列表页顶部那颗会自转的地球；关掉＝整块不渲染，顶栏那枚开关也一起收起。 |
| 列表页顶部 | 两个都显示·概览卡片价值版 | 分组标签行与概览卡片行的六种组合：都不显示／只分组标签／只概览卡片（原版或价值版）／两个都显示（原版或价值版）。价值版把前两张换成「月度预算」与「剩余价值」（按汇率折人民币，拉不到用内置兜底表，故标 ≈；买断与没填价的不计）。 |
| 卡片形态 | 延迟 | 访客默认看到的档。六档：**经典**（2×2 四格）／**简约**（实时速率 + 累计总量）／**延迟**（简约同款 + 三网延迟）／**详细**（再加在线时长、价格与到期）／**总览**（四列小卡）／**紧凑**（一行一台表格，点一行就地展开延迟图）。长相见上面的画廊。 |
| 备注显示位置 | 卡片与详情页都显示 | 四选一：都显示／只卡片／只详情／都不显示。卡片侧＝详细档标题行、总览底注右端、紧凑展开那行（经典与延迟两档卡面不摊）；详情侧＝整页里规格下那一串。 |
| 显示的延迟线路 | 空（自动） | 「三网延迟」（延迟、详细两档）显示哪几条线路：一行一个 ping 任务名（最多三条），留空按后台顺序取前三条；对不上的名字跳过。每 60 秒刷新。 |
| 主题模式 | 随系统设置 | 四选一：随系统／随北京时间自动（19:00–07:00 暗色，固定 UTC+8，跨过切换点会自己换）／亮色／暗色。 |

## 安装

从 [Releases](https://github.com/akanotanin/monitor-theme-rakugaki/releases) 下载 `theme.tar.gz` 上传到
探针后台；之后可在主题卡片上点「从 GitHub 更新」。
